SEC Financial Fetcher — 先讀我
============================================

這個工具會從美國證交會（SEC）的公開資料庫 EDGAR，
抓上市公司的財報，整理成 Excel 檔。


【怎麼開始】

1. 把整個資料夾解壓縮到任何地方（例如「文件」裡）。
   ⚠ 不要只點開 zip 就直接執行裡面的檔案，一定要先解壓縮出來。

2. 雙擊「啟動器.bat」。

3. 第一次執行會自動安裝需要的東西（Python 和幾個套件）。
   看到問句就直接按 Enter，全程按 Enter 就好。
   首次安裝需要網路，大約 3-5 分鐘。


【一定要做的兩件事，不做抓不到資料】

■ 第一件：選語言

  第一次啟動會先跳出一個叫「Language」的小視窗，
  有四個按鈕：繁體中文 / 简体中文 / English / 日本語。
  點一下就記住了，之後不會再問。
  （直接關掉視窗＝用繁體中文，一樣不會再問。）

■ 第二件：填 SEC EDGAR Identity ← 沒填的話一筆資料都抓不到

  程式開起來之後：

    1. 點上方的「進階設定」
    2. 找到「SEC EDGAR Identity」欄位
    3. 填入「你的名字 你的email」，例如：
          Wang Da-Ming wangdaming@gmail.com
    4. 存檔

  為什麼要填：SEC 規定，任何程式來抓資料都必須自報身分，
  否則會被擋。這是 SEC 的規定，不是這個工具在收集你的資料——
  這組字只會送給 SEC，不會傳到任何其他地方。
  email 用你平常在用的就可以。


【之後怎麼用】

輸入股票代號（例如 AAPL、NVDA），按執行，
Excel 檔會出現在這個資料夾裡的 output 資料夾。


【可能遇到的狀況】

■ 雙擊後跳出藍色視窗說「Windows 已保護您的電腦」
  → 點「其他資訊」→「仍要執行」。
     這是因為檔案是從網路傳過來的，Windows 一律會先問一次。

■ 抓不到資料 / 顯示連不上 SEC
  → 先確認網路正常，然後確認上面第二件事（Identity）有填。

■ 顯示「有 N 期沒抓到」
  → 多半是抓的當下網路不穩。網路穩定後重抓一次通常就補得回來。

■ 其他錯誤
  → 資料夾裡的 logs\app.log 有紀錄，把它截圖或傳給對方看。
